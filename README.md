# CozyStyle 🧸💗

Tienda online de pijamas, yetis oversized y prendas cómodas.

## Incluye
- Inicio con banner principal.
- Navegación por secciones: Pijamas, Yetis, Nuevos estilos, Ofertas y Contacto.
- Productos destacados y sección "Más vendidos".
- Carrito funcional con cantidades y eliminación.
- Favoritos guardados en el navegador.
- Carrito persistente usando localStorage.
- Flujo de checkout de demostración con selección de método de pago.
- Sección de envíos a todo Colombia.
- Diseño responsive para celular, tablet y computador.

## Cómo abrirlo
No requiere instalación. Abre `index.html` en el navegador.
